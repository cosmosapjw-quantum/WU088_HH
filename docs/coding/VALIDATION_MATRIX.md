Red failures were observed for expensive-first ordering, physical-core selection, actual native team size, actual orchestrator cost dispatch/completed-state reuse, and dual-provider completion. Numerical equivalence checks are regression tests and do not imply that every one of these tests failed in isolation before implementation. Synthetic/CLI-boundary tests are not scientific data. Owner self-review is not an independent decision reviewer.

The repository test command executes the **new repository suite**, not every historical scientific suite. Old source bytes and scientific arrays are checked by identity and reused. No host speed, full49, interpolation, trajectory, propagation or production claim follows from test count alone.
