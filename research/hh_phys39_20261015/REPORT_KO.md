## 3. Arbitrary-radius positive screened angular coupling kernel

For **any fixed rational r>0**, not only `r=R`,
```
K_lm(n;r) = 1/2∫_-1^1 P_l(mu)P_m(mu) exp[-n s]dmu
          = (2rR)^-1 ∫_|r-R|^(r+R)
                       s P_l((r²+R²-s²)/(2rR))
                         P_m((r²+R²-s²)/(2rR)) e^-ns ds.
```
Each `P_l` is generated as an exact rational polynomial in `z=s²`, the product is also a polynomial; every term `∫s^(2k+1)e^-ns ds` is a positive explicitly endpoint-bounded exponential moment or an exact rational for `n=0`. The implementation caches shared moments across all matrix elements, evaluates the whole finite matrix, and outputs directed **mathematical intervals**, no Gauss quadrature as proof. Result is Legendre-normalized; `Y_l0`-normalized matrix needs factors `sqrt((2l+1)(2m+1))`. This distinction is deliberate.
