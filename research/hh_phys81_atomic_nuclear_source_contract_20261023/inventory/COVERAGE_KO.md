# 최신 관측 범위와 재사용

- GitHub: 접근 가능한 cosmosapjw-quantum repo51개, branch2175개,63 API pages를 끝까지 열거했다. 22개 선택 PR의 actual HEAD를 branch와 대조했다. 전체 branch 본문 감사와 구별한다.
- Exact-head 상세 읽기42건 중40개 nonempty, 알려진 blob10/10일치. 최신 sibling의 실제 source가 오래된 PR 설명보다 앞선 경우 실제 파일을 우선했다.
- Drive 지정폴더508records/501고유이름(top_k1000, completion flag 없음); Dropbox477records/5pages(has_more=false). 이름중복7개는 ID·size로 구분했다. 이름 일치는 내용 동일성 증명이 아니다.
- PHYS80 ZIP의 새 로컬 전체 SHA 및 provider metadata를 확인하고 이전 양 provider full-byte/CRC/144payload proof를 재사용했다. Drive JSON은 새 full bytes 일치, Dropbox extracted text는 newline1byte추가/JSON의미일치다.
- 새 HE34 및 C22D/C22E 백업 기록을 실제 refs와 연결했다. 해당 archive 전체를 새로 받지 않았고 생산자 proof와 fresh metadata/text를 구별한다.
- ChatGPT private conversation/history 조회 capability는 노출되지 않았다. 현재 전달문 및 저장된 handoff/checkpoint/authority만 읽었다. 접근 불가 대화와 미게시 실행의 전수확인을 주장하지 않는다.
- 전체 접근 가능한 repo/branch 및 provider raw audit는 지정된 개인 백업의 S0 audit bundle에 보존한다. 이 공개 연구 unit에는 관련 과학 identity와 집계만 게시한다.

이미 완료한 PHYS78/79/80, HH1231/REI729/HH74control63, C22D H1 4IVP, REC124/125, REI localflows, HE transport/finite-mass component는 재실행하지 않는다. 새 과학 실행 수에 생산자 실행을 합산하지 않는다.
