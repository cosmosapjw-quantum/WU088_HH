## 2. 유한 proof/code/resource 계약

고정 column-conservative Metzler \(K\), 확률벡터 \(\pi\), 비음수 destruction \(d\), \(H=\pi d^T-\operatorname{diag}(d)\), \(A_w=K+wH\)를 유지한다. 전체 허용 \(w\) box의 모든 가측 경로·모든 시작시각에 유효한 full-A \(q,\tau\), 같은 family의 remainder 비팽창성 및 zero-mass whole-domain forcing이 전제다. R11의

\[
q_{\rm add}=\min(1,q_K+\tau M_w\|H\|_1),\quad
b_H=\tfrac12\|H\|_1,\quad
q_{\rm minor}=1-e^{-b_HM_w\tau}(1-q_K)
\]

와 선택 rational-q의 source identity를 재사용한다. Nominal K의 rho를 full A로 직접 옮기지 않는다.

정확한 source partition \(t_0=a_0<\cdots<a_J=T\)에서 \(g_{r,j}\)가 constant upper이면

\[
\overline R(t)=h(t-t_0)R_0+F(t),\qquad
h(u)=q^{\lfloor u/\tau\rfloor},\quad h(0)=1,
\]

\[
F(t)=\sum_{j=0}^{J-1}g_{r,j}\sum_{k=0}^{B}q^k
\left[\min(a_{j+1},t-k\tau)-\max(a_j,t-(k+1)\tau)\right]_+,
\quad B=\lfloor(T-t_0)/\tau\rfloor.
\]

Observation grid는 source grid와 독립일 수 있다. 모든 유효한 \(a_j+k\tau\), 초기 block 경계, observation·source·old-cap knots를 exact rational로 합치면 각 열린 세분 셀에서 \(F\)는 affine이다. 오른쪽 끝점의 왼쪽 극한과 실제 point 값을 구분하여 닫힌 셀 upper를 만든다. Global R convolution memory는 cap 시점에서도 원래 \(t_0\)와 source history를 유지한다.

\(E=|\eta|\), coarse \(\ell^1=4E\), 고정 \(c\ge0\)·signed \(d_c\)를 유지한다. 각 affine segment의 scalar 적분은 양의 Bernstein weights로 전파한다. Whole cap은 같은 source/family/state/clock에서 정확한 interval inclusion·gap-free coverage로, point cap은 정확히 같은 rational 시각으로만 옮긴다. Saved sample이나 endpoint 연결선은 whole-cell cap이 아니다.

유한 영역은 이미 읽은 R12 계약과 연결한다: state 1–13, source/observation/old-cap cells 각각 최대 192, refined cells 최대 2,048, full blocks 최대 8, exact input 최대 1024 bits, \(|d_c|(T-t_0)\le16\). 결합 work guard는

\[
M=(\#\text{refined knots})(\#\text{source cells})(B+1)\le200000
\]

이다. 개별 최대치를 모두 만족해도 이 결합 guard를 별도로 만족해야 한다. 이 turn의 실행 슬롯은 0이다. 상세 수식·코드 위치 대응은 [PROOF_CODE_RESOURCE_CONTRACT_KO.md](PROOF_CODE_RESOURCE_CONTRACT_KO.md)에 있다. 대조에서 새 비정렬 lemma나 구현 결함을 확립하지 않았으므로 이미 있는 과학 검증을 반복할 의무를 만들지 않았다.
