# WU R8: 시간차별 수축을 보존하는 인과적 상계

R7에서 이미 계산한 네 조건부 HD 사례를 사용하여 상계 계산만 개선한다. R6의 같은 계열 H/rho 인증을 시간차별 커널로 조합하고, 부호 있는 coarse damping을 유지한 Volterra 적분을 192개 셀에서 두 번 상방 계산한다. 원래 ODE와 원래 인증은 다시 실행하지 않는다.

현재 DAG **15/32**. 단계 R1–R10 / C1–C10과 연구 DAG는 별개다. CONTRACT.json, WORKFLOW_RECORD.json, EXECUTION_LEDGER.json과 실제 delivery 영수증을 읽는다.
