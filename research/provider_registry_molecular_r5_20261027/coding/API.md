# Callable exact comparison API

Import `{ R5 }` from `src/dynamic_lift.mjs`. Use decimal or fraction strings for all scientific scalar inputs. Matrix rows represent target states, columns source states. `coefficients({K,pi,d,h,f,piDot,scope:'DECLARED_FINITE_MODEL'})` returns exact instantaneous coefficients. `initialBounds(x,c,Xbar)` binds initial model error. `envelopeStep(bounds,c,dt)` returns distinct `endpoint` and whole-interval `interval` enclosures. `envelope(bounds,c,duration,steps)` iterates constant comparison coefficients for1..256steps. Caller must provide constant coefficients or valid interval lower damping / upper forcing bounds; an instantaneous sample is not a time-interval certificate. `projectedState` returns exact full/projected derivatives and flux defect; `generatorFromEdges` accepts explicit rates with scope'SUPPLIED_EDGES_ONLY'.

Outputs serialize exact rational strings through JSON. `approximate()` is for display, not an outward-bound API. Shapes1..9states, normalization, column sums, signs and edge uniqueness are checked exactly. Inherited source physical uncertainty is not reduced by exact arithmetic. Missing transitions/GL2022state rates/consumer remain input obligations.
