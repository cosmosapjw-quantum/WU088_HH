# PHYS89 prepared implementation

The implementation binds recovered CONTRACT revision4 and the unchanged PHYS88
parent source. This preparation performed syntax/AST compilation and dependency
distribution metadata queries only. No parser, fixture, numerical diagnostic,
integration, ODE, benchmark, or packaging job has been executed at this stage.

`FROZEN_FILES.json` lists seven implementation files. `SCIENTIFIC_IDENTITY.json`
binds their hashes, the exact contract, original source and parent identities.
`COMMANDS.json` contains the prescribed bounded primary/reference dispatch and
separate read-only resume commands. Controller authorization remains required
before either scientific child. The lease wrapper is adapted from the parent,
verifies the original full gate SHA, and uses CPU0/CPU8, one worker/thread,
20 CPU seconds and45 wall seconds. It does not retry or terminate peers.

The primary independently preserves all source Decimal leaves and raw tokens,
the full displayed matrix, a single binary64 eigen-decomposition diagnostic,
and an exact negative minor or rational-vector quadratic witness if available.
It does not repair the matrix. The separate reference implements its own
Decimal parser and exact Fraction fixture arithmetic and imports no production
kernel/parser. Shared `evidence.py` is limited to identity, serialization and
complete-payload hash verification.

The manufactured three-group fixture is explicitly synthetic. Its common
energy coefficient rows, normalized sensitivities and shared covariance retain
all six signed energy owners. Counts/caloric require both incoming particles
to belong to the thermal reservoir; positive heat capacity is required for the
capture-only temperature derivative. Clock and density inputs state their
proper-time, volume, lapse and SI conventions in field and method names.

The `--resume` branch verifies the current source/code/contract identities and
every complete payload SHA, then prints SKIP without importing the scientific
kernel, decoding the source, performing numerical work or rewriting results.
Actual read-only resume evidence must be recorded after successful child runs.

`delivery/package_stage.py` takes a full actual published commit SHA and reads
every owned file from native `git show`. It adds exactly one whole parent ZIP
and the explicitly named raw parent MAIN/TERMINAL files. The package manifest
excludes itself from payload hashes and records actual native Git blob IDs.
Restore verification checks whole SHA/size, all ZIP CRCs, member identity, every
payload SHA, actual commit/tree and blob identity, then extracts and rehashes
every member. It never extracts the parent ZIP contents. Packaging has not run.

Physical evaluator mass/deck, target/electron scope, differential scattering
coordinate and supplier, full-support tails and named consumer ACKs remain
open. No physical finite-temperature rate or production admission is supplied.
HH_R10 remains OFF. A displayed-matrix counterexample is not a strong no-go for
the evaluator or a physical model.
