# Bounded resumable W1 range tiles

This adapter preserves the frozen range-native executable and validated callback arithmetic. It reuses the prior accepted tile 00 by its immutable SHA-256. The remaining tiles use the existing sixteen exact W1 plans with 128-bit arithmetic, relative goal 128, component radius 2^-52, 200,000 evaluations, 1,024 integration calls, 120-second internal wall budget and 125-second native external wall/CPU caps. Collection requires all sixteen accepted rectangles and checks the exact component sum against 2^-48.

`prepare --directory NEW_DIRECTORY --workers 3` creates a source-bound manifest. `run --directory DIRECTORY --prepared-sha256 SHA --max-new-tiles 15` dispatches missing tiles in index order, fills at most three process slots on this host, stops new dispatch after the first failure, and drains in-flight workers. `inspect` accepts the same directory and SHA and revalidates saved evidence without scientific execution. Four workers are implemented but refused by the current 8 GiB memory admission: each Python wrapper and native process is conservatively charged 1 GiB separately, with 2 GiB reserved for the dispatcher and host.

The additive process host substitutes only the frozen Python driver's `execute_bound_native` function. The imported tile 00 has the exact historical wrapper. New results additionally require the pinned host identity, retained native stdout/stderr, their byte hashes, exact parsed stdout equality, normal completion, positive source-bound native-output evidence and no timeout. Original driver/build/source/archive/plan/backend/linkage/radius checks remain mandatory. No MPI invocation or NCP benchmark is implied.

Each tile gets create-only dispatch and terminal records. Previously accepted normalized records are reconstructed from their original receipts on resume; normalization self-hashes alone are insufficient. Clean partial sessions can resume without recomputation. Existing claims, partial terminal records, or unresolved dispatches stop automatically: the adapter does not guess whether an interrupted tile ran and never silently reruns it. Rejected tiles end this fixed campaign. A later changed numerical contract requires a new campaign identity.

The outer Python workers run single-threaded launches with all common numerical-library thread counts set to one. A compiled parent-death launcher protects the dispatcher→worker→native chain; the native launch additionally denies process/thread creation. Normal native completion includes direct `wait()` evidence. Abnormal ancestor death guarantees termination through the tested host boundary, not native reaping by a still-running Python parent. The runner does not claim cgroup containment, power-loss transaction recovery, endpoint inclusion, full-domain coverage, normalization, physical-model adequacy, or production admission.

Owner tests read the historical tile receipt without rerunning it. Synthetic tests exercise accuracy/identity refusal, exact collection gaps and duplicates, missing claims, unresolved dispatches, stdout tampering, timeout refusal, and stop-dispatch/drain-inflight behavior. They do not count as HH execution or independent review.
