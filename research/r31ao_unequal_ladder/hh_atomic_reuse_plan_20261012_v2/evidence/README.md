The last file's response paths are relative to the original intake directory, supplied in the complete delivery package as remote_intake/. Its five response objects are actual tool-request/result serializations, not raw HTTP byte captures. No fresh restore test is claimed.

It checks original input/copy identity, DAG dependencies, declared event bookkeeping and current entry points. It does not execute PHYS12, native, source-inclusion or EoR kernels, and does not renew their scientific certification.

Publication and backup results are detached delivery evidence produced after the reviewed plan has been frozen. Actual commit, branch, PR, archive SHA and remote ACKs are recorded from returned data, without embedding an invented self commit in this candidate.
