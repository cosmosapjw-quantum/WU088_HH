# W3 accepted-union collector

This module is a new bounded contract. It does not relax the frozen predecessor's
sixteen-tile cap and never launches an endpoint or native-integral worker.

`context()` verifies the pinned W1 input, native build, binary, actual linkage and
guarded host, then reads the exact prior W3 endpoint plan and result. Its `w1_ctx`
remains separate from the new `global_plan`. `make_plan(ctx)` binds the exact prior
289-cell Cartesian geometry, source identities, endpoint evidence, fixed pilot
scope and this validator's source SHA. `local_plan(ctx, plan, cell_id)` uses the
unchanged endpoint planner to generate a local native input contract, without
evaluating endpoint bounds.

`import_w1(ctx, plan)` calls the pinned original `load_prepared` and `load_state`.
This validates all raw receipts, original requested limits, original terminal
dispatch/return records, normalized records, source-bound stdout and process-host
receipts. The only historical stdout exception is the predecessor's exact pinned
tile-zero receipt. The recomputed exact sixteen-cell sum must equal the pinned old
collection. Unchanged primitive, input, kernel/build, backend and physical windows
are required before new provenance is attached. No original record is overwritten.

Every reused record retains `origin.requested_radius_exp=-52`; it is never
relabeled as an execution requested at -57. Its exact serialized radius must also
satisfy the new per-cell bound `2^-57`. This is checked after original-evidence
validation. The actual sum is the preserved W1 rectangle, component by component.

`normalize_new(ctx, plan, cell_id, receipt_path)` admits only pilot IDs
20, 52, 105, 57. It requires the fixed 128-bit, -57 native limits, exact local plan,
raw stdout/receipt equivalence, process-host identity and normal completion. It
does not authorize dispatch; the separately bounded root runner owns dispatch.

`collect_partial(plan, records)` sums only trusted normalized records with exact
Fractions. Its seals are integrity checks, not authentication of arbitrary caller
input; callers must first use the raw-evidence normalization paths. Duplicate IDs,
duplicate raw receipts, wrong origins/source/geometry, noncanonical rationals,
reversed intervals and mismatched or too-wide radii are rejected. The output lists
the actual accepted-cell union and all missing IDs. Missing contributions are
explicitly unbounded and excluded, not assumed zero. Endpoints and final physical
normalization are excluded. No full-D, scientific or production admission follows.

This scope allows at most the sixteen old cells plus four pilot cells, so complete
289-cell coverage cannot be reached here. A future expanded campaign requires a
new explicit source-bound execution/normalization contract. Even a complete
compact-interior collection would still exclude the endpoint contribution.

Tests read preserved raw evidence and synthetic rejection fixtures only. They
never execute a numerical solver. New actual pilot receipt acceptance is checked
separately by the parent runner and independent reviewer.
