# HH-PHYS01: 광이온화–HH 경쟁의 국소 물리 응답

고정된 기존 FT03+LCS 국소 source 의미를 유지한다. 새로운 근/시간이력/NCP dispatch는 없다.
1. 에너지/열/입자수/동일입자 counting 규약을 원 source에 결속한다.
2. 일반 smooth 비광자 H/He 반응을 포함하는 벡터장의 광자 source×HH 혼합 Taylor 계수를 유도한다. 연속 source와 BEfull/two-half를 구별한다.
3. 기호 독립 경로 및 저장 state에서 80자리 단일점 계수/단위/극한/ledger를 검산한다. 유한 실제 h에 대한 remainder bound는 OPEN으로 둔다.
4. source/결과/검사/원로그/claim과 다음 정확 source 검증 의무를 패키징하고 기존 cloud에 create-only 백업한다. 가능한 비강제 additive publication만 수행한다.

분석 profile: HH-PHYS01_FROZEN_LOCAL_MONOCHROMATIC_MIXED_RESPONSE. 무한범위 물리모형, actual owner macro 또는 ENERGY06E certificate로 승격하지 않는다. 새 파일 output은 create-only이다.
