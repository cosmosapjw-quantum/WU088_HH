# Host synthetic readiness scope

This loop implements the next node identified by the published G0–G6 handoff.
Its acceptance is executable host preparation, evidence collection and synthetic
software verification. It is not an actual HH numerical certificate run.

The source pins remain FLINT 3.4.0, GMP 6.3.0 and MPFR 4.2.2. The prior overlay
is immutable and `INPUT_LOCK.json` binds its 56 implementation/test source files.
Offline host building uses a new sidecar directory and never installs into the
original scientific runtime. Backend libraries and synthetic executables are
built only when the explicit host-execution entry point is invoked. This chat
loop does not invoke that entry point, following the user's master prompt §8.

Current-host NumPy sentinel generation is a software diagnostic. It is never a
historical producer witness without an independently reviewed historical link.
No tool in this new ABI collector accepts actual HH arrays. Exact archive hashes,
output-member byte identity, layout semantics, execution provenance and reviewer
admission remain separate claims. A current probe or a self-hashed JSON record
does not close B03.
