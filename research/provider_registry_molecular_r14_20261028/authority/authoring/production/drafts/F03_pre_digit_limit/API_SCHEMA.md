# R14 production/reference exchange schema (authoring; NOT_RUN)

Input preserves R13 fields `id, states, q, tau, c, d, initial:[R0,E0], source_knots, observation_knots, binding, certificate`. Scalars are exact rational strings/integers; all output Fractions serialize to reduced rational strings. Public string grammar is ASCII `[+-]?[0-9]+(?:/[+-]?[0-9]+)?`, checked before integer/Fraction conversion, with length<=2048 and reduced numerator/denominator<=256 bits. Leading/trailing whitespace, decimal and exponent notation are unsupported. Signed denominators are parsed as bounded integers then normalized by Fraction. `g_r` and `g_e` each contain one original degree-two Bernstein triplet `[b0,b1,b2]` per original source cell. Signed middle coefficients are allowed when exact endpoint/interior-minimum positivity passes. No generic cap fields accepted.

Canonical forcing payload is `{schema:"WU_R14_WHOLE_FORCING_V1", source_id, clock_id, clock_unit, state_order, source_knots:[str(Fraction)], g_r:[[str(Fraction)]], g_e:[[str(Fraction)]]}`. SHA256 of UTF-8 `json.dumps(payload, ensure_ascii=False, sort_keys=True, separators=(",", ":"))+"\n"`. Binding and certificate use `whole_forcing_hash_format="WU_R14_WHOLE_FORCING_V1"`, equal `whole_forcing_source_sha256`, and actual `FIXTURE_SOURCE.json` SHA as `source_sha256`. Whole-forcing hash describes the ORIGINAL source, never effective split. Source certificate flags/scalars/identities follow R13.

Production `run_case(case)` returns:

- `parameters`: q,tau,c,d,initial,t0,T,states,full_blocks,binding,certificate.
- `source`: original `knots,g_r,g_e`; `effective_source`: `knots,g_r,g_e,original_cell_indices,source_vertex_times`. Each effective triplet is nonnegative and exact-equivalent to its original restriction.
- `requested_times`: observation knots; `base_times` and alias `refined_times`: exact rational translated-effective-knot union with observations. No critical root is added to this propagation clock.
- `exact.F_at_refined`, `R_at_refined`, `kernel_at_refined`: exact rational arrays. F continuous; R actual right-continuous endpoint (including final T).
- `exact.R_cubic_cells`: one row per base cell; row `left,right,bernstein` (four nonnegative coefficients), `coefficients_normalized` (power coefficients `[a0,a1,a2,a3]` for x=(t-left)/(right-left)), `initial_piece,F_bernstein`, `right_left_limit,actual_right_endpoint`, `ge_bernstein` (quadratic restriction), `forcing_bernstein` (four coefficients for cR+ge), `critical`, `supremum`. Additional `whole_E_majorant` holds `forcing_upper=c*supremum.exact_upper+max(ge_bernstein)`, `left_E_upper`, `right_majorant_upper`, and `supremum_upper=max(left_E_upper,right_majorant_upper,next_polynomial_endpoint_upper)`. The positive quadratic coefficient hull for ge is a bound, not a claim of exact ge maximum.
- `critical`: `derivative_power:[C,B,A]`, `exact_roots:[{x,multiplicity,location}]` including endpoint roots explicitly, `root_boxes:[{lo,hi,iterations,derivative_at_lo,derivative_at_hi,branch}]` strict-interior sign brackets, `bisections_actual`. Exact roots can be rational branch zeros or exact bisection hits; boxes have width<=2^-96 and opposite derivative signs. Endpoint roots are listed with location `LEFT_ENDPOINT`/`RIGHT_ENDPOINT`; interior location `INTERIOR`. All-zero derivative uses `degree=-1` and `constant_polynomial=true`, no continuum root list.
- `supremum`: `exact_lower,exact_upper,exact_gap,M_B,Cmax,proved_gap_bound`, `dyadic_lower,dyadic_upper`, `box_bounds:[{lo,hi,bernstein,midpoint,midpoint_value,hull_upper}]`, `exact_candidates:[{x,value,kind}]`. Candidate `RIGHT_LEFT_LIMIT` is distinguished from actual endpoint. The rational bracket is not an exact irrational supremum. `proved_gap_bound=M_B*2^-96`.
- `exact.observation_R_suprema`: aggregate exact lower/upper/gap and max local proved gap per observation cell.
- `raw`: R13-compatible `endpoints_lower,endpoints_upper,whole_cells_upper,refined_endpoints_lower,refined_endpoints_upper,refined_whole_cells_upper`; additionally `whole_cells_lower,refined_whole_cells_lower`. Point R is exact rational. Whole R is outward dyadic of exact supremum enclosure. Whole E lower=max endpoint lower witnesses, upper=constant-forcing majorant with exact R sup upper and positive quadratic ge hull. E endpoint recurrence uses only rational base times. `coarse_l1_multiplier=4`.
- `weights`: per base-cell `left,right,exp,W0,W1,W2,W3,phi` intervals encoded `[lower,upper]`, `d_delta,positive_series_tail,argument_interval,method`. phi=sum Wi; all weights positive/nonnegative; d=0 is exact exp1 and outward duration/4 weights. Negative d uses exp(z) and reversed positive moments.
- `work`: `original_source_cells,effective_source_cells,base_cells,refined_cells,full_blocks,overlap_terms_upper,overlap_terms_actual,nonempty_overlap_terms,root_bisections_upper,root_bisections_actual,guard_applied_before_overlap,guard_applied_before_root_isolation,coefficient_cell_builds,overlap_limit,root_limit`. Full overlap charge Nbase*Neffective*(B+1), roots2*96*Nbase, fixed before coefficient/root construction. Actual overlap count is every loop combination, equal to precharge. Nonempty count is geometry U(mid)>L(mid), including zero q-power or identically-zero source terms. Coefficients built once; all output queries reuse them.
- `R_history="GLOBAL_FROM_ORIGINAL_T0"`, `cap_application="NONE"`, explicit declaration-versus-physical certificate scope and arithmetic metadata.

Primary `PRIMARY_RESULTS.json`: top-level `schema,status,cases:[{id,input,result,execution_error?}],checks,guards,summary,execution,input_and_code_sha256,scope`. Each valid-case result uses schema above. Fixed `CASES.json` holds `cases`, `guards`, input-kind/frozen numerical guard; controls and relations remain separate from original source payload in `FIXTURE_SOURCE.json`. Guard rows use either a complete invalid input or finite scalar/work-operation challenge and `expected_error_substring`. Saved guards have `id,expected_error_substring,observed_error_class,observed_error,status,guard_scope`. Direct work-budget challenges are explicitly distinct from accepted-domain convolution cases. `controls.whole_R_sup` is `{rational, sqrt_coefficient?,radicand?,observation_cell}` for an independently hand-derived rational/surd supremum.
