# C2 public typed interface and source-identity guard

`python3 src/cli.py --source authority/PUBLISHED_TWO_POINT_TRANSCRIPTION.json --output NEW_FILE.json` accepts only **exact declared transcript** with two temperatures 205/295 K, DOI 10.1063/5.0128598, SQM channel H+ + HD -> D+ + H2, and source units 1e-10 cm3/s. Source input is UTF-8 JSON, exact printed decimal **strings**, no floats, no stale source rows. It writes a create-only deterministic report of SI conversion, printed signed differences, ratios relative to **printed halfwidth**, and the author's global fitted expression evaluated only at those two temperatures. The schema exposes `state_resolved_admitted=false`, `physical_consumption_admitted=false`, and `new_science_nodes=0` with no override.

The numeric reference is a **separate algorithm** using `mpmath` with 95-digit precision and fractions built from `Decimal` source strings. Production uses `decimal.Decimal` with 100-digit precision plus exact `Fraction`; no fitting or ODE model is performed. The comparator enforces 6 exact comparison equalities and 4 pre-frozen absolute 1e-85 high-precision differences. Tests of data mutation and missingness reject unsupported source variants.
