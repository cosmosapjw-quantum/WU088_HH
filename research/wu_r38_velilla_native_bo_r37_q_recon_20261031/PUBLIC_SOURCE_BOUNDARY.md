# Native PES source identity and publication boundary

Full original AIP EPAPS Fortran `h3plus.f` and PDF are preserved only in private backup capsules, not republished in this Git branch. Their hashes are in `evidence/PROVENANCE.json`.

This PR contains new derived Python code, source-locked numerical crosswalk inputs as private archive references, and the 190-channel and 1,920-case public result summaries. All 19,200 product-state rows are preserved in the Library + Google Drive source ZIP **and** as deterministic `.csv.gz` scientific data files on this branch (no original source file redistribution).

Historical native-source R38 spectral and FD replay Python scripts are under `upstream_spectral/` and `upstream_fd/` with their immutable archival source-ZIP identities. They do not reconstruct the original PES coefficients without the user's authenticated EPAPS supplement.
