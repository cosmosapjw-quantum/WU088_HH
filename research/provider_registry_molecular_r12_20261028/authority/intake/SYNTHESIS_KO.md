## 선택

R11 FINAL을 보존하고 별도 R12에서 **비정렬 rational source/observation grid의 정확한 forcing convolution과 닫힌 셀 cap 세분화**를 수행한다. 이번 실제 GitHub 변경 원문, 새 backup 원본, 첨부 및 공식 HD 배포 경로에서는 actual HD reactive array와 named WU physical consumer/state/density/clock 결속을 확보하지 못했다. 따라서 입력 상태는 INPUT_PENDING이며, 확보되지 않은 범위를 전역 자료 부재로 해석하지 않는다.

사용자의 현재 명시적 전수조사 지시에 따라 접근 가능한 최신 목록을 갱신했다. 완료 과학과 ODE 및 이전 독립 심사를 반복하지 않는 R11 규칙은 유지한다. 명시적으로 선택한 physmath 플러그인1.3.0의 full R1–R10/C1–C10을 새 단위에 적용하고, 이전 버전·기록을 고치지 않는다.

## 새 이론으로 연결

R11은 모든 시작시각과 전체 w family에 유효한 q와 h(age)=q^floor(age/tau),h0=1을 이미 증명했다. 현재 구현의 제약은 uniform delta와 정수 tau/delta다. 새로운 source/observation clock을 반올림해 그 인덱스 공식을 재사용하면 forcing의 실제 위치와 block jump를 바꾼다. R12는 interval overlap 길이로 convolution을 정확히 계산하고, 모든 source knot의 k*tau 평행이동과 기존 cap경계를 합친다. 각 열린 세분cell의 R은 affine이므로 기존 positive Bernstein arithmetic을 재사용할 수 있다.

이 선택은 실제 새 입력을 대체하는 물리 가정이 아니라 독립된 조건부 방법 확장이다. Whole fine/coarse-domain forcing, fixed K/pi/destruction, 모든 시작시각, 같은 source family/state/clock, 정확한 closed-cell coverage가 그대로 전제다. R11의23/38개 객체를 모두 보존하고 새 이론·코드2개를 OPEN으로 등록하여23/40이며, 실제 독립검증·채택 전에는 완성노드를 늘리지 않는다.
